# Contributing
- Never change `applicationId`/`namespace` (`com.bodyscope3d.app`).
- Bump version only in `version.properties` + `VERSION` + `CHANGELOG.md`, then tag `vX.Y.Z`.
- Never commit keystores, `keystore.properties`, `google-services.json`, tokens.
- Do not mark an asset READY unless the file exists and its license is recorded in ASSETS.md.
